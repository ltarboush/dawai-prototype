# Dawa’i | دوائي — Interactive Prototype

Single-page interactive demonstration for MEDATHON. Uses fictional data; not connected to a hospital and not clinically validated.

## Publish on GitHub Pages
1. Create a public GitHub repository (for example `dawai-prototype`).
2. Upload `index.html` to the repository root and commit it.
3. Open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
4. After GitHub finishes deploying, open `https://YOUR_USERNAME.github.io/dawai-prototype/`.

No build process, hosting server, or third-party dependencies are required.

For best viewing, use a desktop browser with a wide window: the original prototype uses a fixed 1600 × 900 layout.
